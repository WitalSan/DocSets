# Инструкции репозитория

- Все текстовые исходные файлы должны храниться в кодировке UTF-8.
- Русский текст должен оставаться читаемым. Нельзя сохранять искажённый текст (mojibake), например `РР·...`.
- Сохранять существующий стиль окончаний строк, если задача явно не требует его изменить.
- Комментарии писать на русском языке.
- Поля классов именовать в формате `_camelCase`.
