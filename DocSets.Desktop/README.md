# DocSets Desktop

Самостоятельное приложение для работы с каталогами `*.DocSets` без запуска
Visual Studio.

## Сборка

```powershell
dotnet build DocSets.Desktop/DocSets.Desktop.csproj -c Debug -m:1
```

Результат находится в
`DocSets.Desktop/bin/Debug/net8.0-windows/DocSets.Desktop.exe`.

## Первый запуск

1. Выберите **Файл → Открыть DocSet** и укажите каталог `*.DocSets`.
2. Либо выберите **Файл → Создать DocSet**, укажите родительский каталог и имя.
3. Расположите общие панели удобным образом. Раскладка восстановится при следующем
   запуске.
4. Для возврата к исходной раскладке используйте **Панели → Сбросить расположение**.

## Общий интерфейс

- дерево закладок;
- свойства выбранного узла;
- HTML-заметка Jodit;
- исходный код и preview;
- поиск;
- журнал сообщений.

Настройки приложения и раскладка сохраняются в
`%LocalAppData%/DocSets/Desktop`. Сам документ и его изображения остаются внутри
выбранного каталога `*.DocSets`.

Desktop и VSIX используют один `DocSetsViewModel`, один
`DocSetsWinFormsControl`, одно дерево `TreeViewAdv` и один набор команд. В Desktop
нет адаптеров-копий дерева или панелей.

## Ограничения среды Desktop

- переход к Roslyn-символу доступен только в VSIX; Desktop открывает файловую
  позицию, если она сохранена в закладке;
- preview кода строится по сохранённому файлу и не видит несохранённый буфер IDE.
